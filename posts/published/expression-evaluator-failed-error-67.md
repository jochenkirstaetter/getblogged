Immer wieder faszinierend, welche Fehlermeldungen einem über den Weg laufen können:  
  
Expression evaluator failed (Error 67)  
An internal consistency check in the Visual FoxPro expression evaluator failed. This might be caused by a damaged Visual FoxPro object code file.  
Recompile the program that caused the error.  
  
Zum Glück ist die Aufforderung korrekt und nach einem Recompile ist das Problem weg. Nunja, Füchse eben...
